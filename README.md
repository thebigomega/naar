# Naar Chat

A minimal real-time chat app powered by Node.js, Express, and Socket.IO.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm start
   ```
3. Open http://localhost:3000 in your browser to chat.

Messages are broadcast to everyone connected and a lightweight history (last 100 messages) is shared with new visitors.
